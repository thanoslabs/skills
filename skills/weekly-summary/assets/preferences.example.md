# Weekly summary preferences

Copy to `~/.config/weekly-summary/preferences.md` (or point
`$WEEKLY_SUMMARY_PREFS` at your copy) and edit. Free-form: keep only the
rules you care about; anything not stated falls back to the skill's
defaults.

## Window and scope

- Window: Monday to today.
- Include only the `acme` GitHub organization; leave out personal repos.
- Tracker projects: OPS, HELP.
- Chat: team channels only, no direct messages.

## Format

- Header: `*Weekly update - <Mon D>-<D>*`
- Sections: Done, In progress, Next. Fold reviews into one line under Done.
- At most 8 bullets in total.
- End each line with the ticket key in parentheses; no PR links.
- Mention when I was on call for the week in the header.
